The first beta of Krova 0.2. **Windows only, pre-release.** It adds a lot: auto-arrange, stacks, workspaces, focus tools, a quick panel and a new settings app. All of it passes the automated tests, but **none of the new features has been tried by hand on a real Windows desktop yet.** Please treat this as a test build, not something to rely on, and report what you find.

If you want the stable version, use [v0.1.0](https://github.com/nAItiklearn/krova/releases/tag/v0.1.0).

## Download

`Krova-windows-x64-setup.exe`: a per-user installer for Windows 10 and 11 (64-bit). It does not ask for administrator rights. Check your download against `SHA256SUMS.txt`:

```powershell
Get-FileHash .\Krova-windows-x64-setup.exe -Algorithm SHA256
```

### The installer is unsigned

Krova is not code-signed, so **Windows SmartScreen will show "Windows protected your PC"**. Select **More info**, then **Run anyway**. The warning is about an unknown publisher, not about anything Windows found in the file. A matching checksum shows the file was not corrupted in transit; it can't prove who built it. If you would rather not run an unsigned installer, build from source (see the README).

### No macOS build

The macOS code compiles and passes its checks in CI but has never run on a Mac, so there is no macOS download.

## What's new

**Arrange without dragging**
- **Auto-arrange** (per monitor): a new window goes to the next free zone of the active layout. Policies: main zone first, fill gaps, stack when full.
- **Stacks**: when every zone is taken, windows stack in a zone. A slim tab strip on the zone's top edge shows each window's icon and program name (never its title). Click a tab, scroll over the strip, or press `Ctrl+Alt+[` / `]`.
- **Swap**: drop a window on an occupied zone, or press `Ctrl+Alt+Shift+Arrow`.
- **App rules** by program name: never touch, always float, or a preferred zone. Dialogs and tool windows are never arranged.
- **Preset layouts**: grid, columns, rows and main + side, with ultrawide and portrait variants.

**Keyboard**
- A new default scheme on `Ctrl+Alt`: arrows move a window between zones and monitors, `1`–`9` send it to a zone, `Shift+1`–`9` apply a layout, `Enter` fills the screen and restores, `Space` opens the layout switcher, `/` shows every shortcut, `T` pauses, `F` turns on focus dim.
- **Rebind any shortcut** or switch it off. Krova checks for clashes with its own shortcuts and with other programs, and suggests free ones.
- If your config still uses the old `Win+Alt` modifier, the zone shortcuts keep it.

**On screen**
- **Notch**: a small pill at the top of the main monitor showing the active layout, with a menu.
- **Quick panel**: click the tray icon for the active layout per monitor, auto-arrange, pause, focus tools and the switcher, without opening the full settings window.
- **Layout switcher**: a deck of your layouts for the monitor under the cursor.
- **Hover picker**: hold the modifier over a window's title bar to pick a zone.
- **Hot corners**: run an action (pause, switcher, focus, calm desk and more) when the cursor reaches a screen corner.
- **Window highlight**: a border or soft glow around the active window.

**Workspaces and focus**
- **Workspaces**: save the programs on screen with their zones and bring them back later. Krova launches the missing ones and minimises the rest; it never quits a program. Only program paths are stored.
- **Focus dim**: dims everything except the active window's zone.
- **Calm desk**: minimises the windows that aren't in a zone; toggle it again to bring them back.
- **Share-safe**: for screen sharing. Hides program and layout names in Krova's own windows and keeps the panel, switcher and picker out of screen captures.

**Also**
- A new settings app with a sidebar: Overview, Layouts, Arrange, Workspaces, Focus, Shortcuts, Appearance, Corners, Displays, Screen edges and Privacy.
- **Reserved screen edges** per monitor, for third-party docks and bars.
- **Focus follows mouse** (off by default, with a delay).
- **Pause** from the tray, the panel, the notch, a hot corner or `Ctrl+Alt+T`. Windows stay where they are.
- **Appearance**: accent colour, corner radius and border width, used by every on-screen overlay.
- A new ink-and-ember app icon.

Krova still makes no network calls, collects no telemetry, and never reads, logs or stores window titles.

## Not tested yet

Everything new above has passed unit tests, Rust integration tests and browser tests of the settings app against a mock backend. **Nothing new has been run by hand on a real Windows desktop as one build.** In particular, these are untested:

- Auto-arrange, stacks and their tab strips with real programs; swap by dragging.
- The new shortcuts on a physical keyboard. Some PCs refuse some `Ctrl+Alt` chords (for example, older Intel graphics drivers use `Ctrl+Alt+Arrow` for screen rotation, and IDEs use `Ctrl+Alt+Left/Right`). The Shortcuts page says which ones Windows refused.
- **Focus follows mouse** may be blocked by Windows' rules about which program may bring a window to the front.
- Workspaces restoring real programs; calm desk; focus dim and the highlight overlay at different scaling settings.
- Share-safe capture exclusion with real screen-sharing apps.
- Hot corners, the notch and the hover picker on multi-monitor and mixed-DPI setups.
- Idle CPU and memory with all the new features on (v0.1's numbers were measured; 0.2's haven't been yet).

Other known limits: languages other than English show English text for now; windows of programs running as administrator are skipped; some programs enforce their own minimum size.

Bugs and results from your setup are welcome as issues.
